curl -fsSL https://downloads.callayers.com/linux/install.sh | sudo bash

One command installs Callayers and its camera. Intel/AMD x64; Ubuntu versions are listed above. Secure Boot must be off. Updates come through your package manager. Debian 12/13 and compatible Mint/Pop!_OS releases are experimental: add --allow-experimental to the installer arguments (sudo bash -s -- --allow-experimental).
